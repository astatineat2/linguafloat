# LinguaFloat

Windows 桌面翻译工具，支持选中文字、输入、屏幕区域 OCR 和 PDF/Word/PPT 文件翻译。

## 下载

前往 [最新稳定版](https://github.com/astatineat2/linguafloat-releases/releases/latest)，下载完整 `win-x64.zip`，完整解压后运行 `LinguaFloat.exe`。无需安装 Python，不要只复制 EXE。

软件 ZIP 约 492 MiB，解压后约 1.21 GiB。更新还需容纳下载包、新版和旧版备份，请额外预留至少 2 GiB；首次 PDF 所需资源另计。`corresponding-source.zip` 是开发与许可证所需的对应源码，普通使用无需下载。

开发仓库私有。每版二进制另提供许可证要求的对应源码附件；GitHub 自动生成的 Source code.zip 不是该附件。

软件默认不会上传文件或发起付费翻译。配置自己的供应商并主动翻译时，文字会发往该供应商，费用以其账户计费为准。

首次指南、许可证、更新日志随完整包提供。程序内“帮助与更新”可查看指南和检查稳定版。
当前没有 Windows Authenticode 签名，请核对正式发布的校验信息，不要关闭安全软件。

若更新提示连接失败，请检查网络能否访问 GitHub 的下载域名；能获取 GitHub API 信息不代表附件下载一定可用。可使用自己的系统代理或进程代理环境，软件不会替你修改全局代理设置。

下载附件包括完整便携包、匹配对应源码、签名更新信息与 SHA-256 校验清单。稳定版本按 vX.Y.Z 标签发布。
