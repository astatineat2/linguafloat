# v0.11.0 验证记录

本版同时更新 GUI、独立更新助手和文档运行时。未调用付费翻译 API，未上传用户论文、译文、配置、数据库或缓存。

## 已完成

- 最终更新安全、帮助、单实例、任务回调及输入翻译测试：62 项通过。涵盖 RSA/CNG 签名、非法附件、路径穿越、校验、中断续传、限流、失败回退、安装等待和现有请求回调。
- 发布流程测试 2 项通过：续传已匹配的草稿附件，不覆盖已上传文件；校验不匹配时不得公开。
- 既有 UI/API 等回归：153 项通过；文档、参考文献及科学内容相关抽样：60 项通过；表格与轴标题 3 项通过。模拟与本地排版测试不代表真实供应商翻译或整篇 PDF 质量验证。
- 编译后的更新助手进行实际本地 0.10.0 → 0.11.0 安装、健康确认；故意损坏的新程序启动失败后实际回退通过。
- 本地升级前后数据库计数一致：cache 422、jobs 21、request_quota 18、request_events 205。用户密钥不进入更新请求。
- 完整构建检查：44 个应用模块及 6 个图片资源与源码匹配，独立更新助手与发布公钥存在。
- 当前 Windows 主机上用空白 APPDATA/LOCALAPPDATA、无系统 Python PATH 启动便携版。首次指南正文可见且可滚动；文档运行时独立导入 Python 3.13.13、BabelDOC 0.6.2、pdf2zh-next 2.9.0、PyMuPDF 1.25.2 成功。
- 首次指南原先因控件被提前加入后移出标签页而保持隐藏；移除多余标签页操作后重新构建并实测可见，增加可见性断言。
- 精确锁定 GUI/文档依赖，校验 3 个实际 OCR 模型与 12 个图标字体。OpenCV/Tencent 共享源文件对应到实际 wheel 并提供副本。
- 上游 AGPL/GPL/LGPL/MPL 源归档与许可证随对应源码附件提供；QtPdf 对应 qtwebengine。开发历史保持私有。

## 范围与限制

- 隔离配置验证在当前 Windows 主机完成，尚未使用全新 Windows 虚拟机；不代表所有 Windows 10/11 版本或硬件均已验证。
- 本机 Ctrl+Alt+Y 被其他程序占用，界面如实提示；未改动用户快捷键配置。
- 当前没有 Windows Authenticode 签名；更新元数据另使用 RSA-3072/SHA-256 签名，软件包使用 SHA-256 和完整结构校验。
- PDF 首次使用可能按需下载布局模型和字体；本轮不重复进行真实 API 翻译或整份论文回归。
- Qt/MuPDF 采用匹配的官方 wheel；上游原生源码的完整重编译、逐字节可复现构建尚未验证。
- 原生更新安装与回退已本地实测；后续两个不同正式版本之间的互联网升级，需在下一版发布时继续验证。首发版本可验证公开下载、签名和当前版本检查。

固定启动目录为 `exe/LinguaFloat.exe`，历史备份独立保留。公开发行使用固定 `v0.11.0` 标签，不覆盖已公开附件。
