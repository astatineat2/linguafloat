# v0.11.1 验证记录

在 v0.11.0 首次公开发行后的真实检查中，GitHub 未登录 API 返回限流；公开 Release 附件本身可以下载。v0.11.1 增加签名元数据备用通道，继续尊重 API 退避，不在软件内加入 GitHub 凭据。

- GitHub API 返回 403/429 时，读取同一受信仓库的 `releases/latest/download/update.json` 与签名。API 退避期间不重复请求 API。
- 备用通道仍执行受信公钥的 RSA-3072/SHA-256、架构、版本、来源、文件大小与校验验证；签名损坏时不接受更新，不降级安装。
- 更新、帮助、单实例、任务回调、输入翻译与发布流程测试共 66 项通过；新增限流备用通道、API 退避和篡改拒绝测试。
- 无登录凭据的真实网络检查已使用正式 v0.11.0 签名附件验证成功。不能把这一结果当作两个正式版本间的安装已通过；v0.11.1 发布后的下载和安装另记录实际结果。
- v0.11.0 的原生助手安装、失败回退、隔离配置启动与文档运行时验证继续有效；见 verification-v0.11.0.md。本补丁同时更新 GUI、助手及版本化文档运行时，不改翻译引擎或 API 计费配置。

仍未进行全新 Windows 虚拟机或完整原生依赖重编译验证；程序没有 Authenticode 签名。未调用付费翻译 API。旧版本、用户配置、凭据、缓存、历史与输出保留。
