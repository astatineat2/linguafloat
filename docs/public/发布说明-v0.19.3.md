# LinguaFloat v0.19.3

Windows x64 完整便携版，累计包含 v0.17.0 build1 之后的本地修复。不提供新安装程序，安装验收仍暂停。

## 主要变化

- 可靠原生表格的中文表头按完整单元格组合，紧凑换行并水平、垂直居中；保留科学标识的原始矢量字形、字号、斜体和上下标。数据、表线和背景不移动。
- 独立表格默认随正文翻译；底部“图片翻译”只在正文完成后补译图内文字，确认后才开始，结果另存且关联原任务。旧任务需有完整材料，不自动重翻正文。
- 新任务默认宋体与 Times New Roman，中文可选微软雅黑；使用本机字体，不分发 Windows 商业字体。改善出版日期、作者邮箱/ORCID、正文尺度、公式和样式保护。
- 改善参考文献区域保护、请求排队和重试诊断、任务终态同步及图表故障的部分完成交付；不把局部保留当作成功翻译，也不关闭数值保护。

## 验证与限制

本版表头修复已对 11 页原始文档和对应输出实际渲染检查：14 个表头文字组居中，21 个科学词组的内部字形位置保留；132 个数据单元格的字形和像素不变。相对于修复前输出，表头外的页面像素不变，单语和双语缓存重排结果一致。这是特定材料和机制的验证，不代表所有文档语义或图表质量均已通过。

本轮表头修复及发布准备不请求真实翻译或列模型接口，也不附送用户论文、译文、配置、历史、缓存或凭据。此前授权的局部真实验证不等同于本轮重新验证所有供应商。

扫描、旋转或结构不明确的表头不强制重组；密集图、小字、复杂纹理或空间不足时仍可能保留原文并记录。图片需要用户另行确认补译，正文处理不会擅自翻译图内内容。

程序未有 Windows Authenticode 签名，全新 Windows 虚拟机、全部硬件兼容性及完整安装/卸载验收未完成。不要关闭安全软件；请核对发布来源和校验文件。
