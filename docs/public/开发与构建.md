# LinguaFloat 对应源码与构建

开发仓库：私有 `astatineat2/linguafloat`。公开发行页：`astatineat2/linguafloat-releases`。
开发历史、密钥、个人资料不进入公开快照；每版公开二进制必须另附匹配的对应源码材料。

## 环境

目前验证构建使用 Windows x64、Python 3.13。GUI 与文档运行时分别建环境，安装精确版本清单：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r app-requirements.lock.txt
py -3.13 -m venv .document-runtime
.\.document-runtime\Scripts\python.exe -m pip install -r document-requirements.lock.txt
```

GUI 环境使用 `packaging` 做版本解析。更新助手调用 Windows CNG 验证 RSA-3072/SHA-256 签名，无新增加密运行时。
发布端生成签名使用现有 `cryptography`，属于构建工具。重新构建源码无需持有原发布者的签名私钥。

```powershell
.\.venv\Scripts\python.exe -m pytest
powershell -File scripts\build_documents.ps1
```

完整内部输出：`app-dist\LinguaFloat`。在实际启动、回归和包检查通过后，用 `scripts/publish_portable.py --source app-dist/LinguaFloat` 更新本地正式目录 `exe`。
构建时必须保留 `release/channel.json` 的公钥，若建立自己的发行渠道则换为自己的公钥和仓库；不能冒用原发行者签名。

## 第三方源码

完整清单见 `LICENSES`、`THIRD_PARTY_NOTICES.md`、两个精确版本依赖清单及 `source-materials`。
正式公开前必须核对 AGPL/LGPL 组件所需源码、补丁、构建说明和再分发声明。仅附项目源码或上游主页链接不足以完成核对。
本地候选包可能尚未完成这些材料；必须查看 `LOCAL-RELEASE-REVIEW.json`，不能把候选包直接上传为正式发行版。

## 签名与发布

`scripts/release_tools.py init-key` 将私钥保存到用户本地的 `LinguaFloatPublisher` 目录，受用户 ACL 保护；只把公钥写入项目。
私钥不得进入 Git、源码包、软件包或 Actions 日志。发布前备份私钥到私有安全位置；丢失时需要受信钥匙迁移或手动换版。

`scripts/release_tools.py prepare --candidate` 只准备本地候选。正式准备要求素材授权、许可材料、完整对应源码和隔离配置运行验证均已记录；全新 Windows 虚拟机测试尚未进行。
同一发布版本附件不可覆盖；任何程序变化都重新编号。公开下载仓库自动生成的 Source code.zip 不是私有开发项目的对应源码。


## 匹配的上游源码与原生构建

`source-materials/source-lock.json` 记录确切版本、下载来源和 SHA-256；归档本体随本版对应源码附件提供。`checksum_evidence` 区分上游公布的校验和与对官方 HTTPS 标签归档的本地计算。

- BabelDOC 0.6.2、pdf2zh-next 2.9.0：按各自 pyproject.toml 构建 wheel；LinguaFloat 的适配和运行时补丁在 src/linguafloat/document_*.py，未直接修改上游包。
- PyMuPDF/MuPDF 1.25.2：同时附 Python 包 sdist 和含第三方源码的 MuPDF source 归档。解压二者，使用 PyMuPDF sdist 内 docs/src/installation.rst、setup.py 和 scripts/mupdfwrap.py 的 Windows 构建说明；PYMUPDF_SETUP_MUPDF_BUILD可指向匹配的本地 MuPDF 树，避免隐式取得另一版。
- Qt/PySide/Shiboken 6.11.2：附 pyside-setup、qtbase、qtdeclarative、qtsvg、qtdatavis3d、qtvirtualkeyboard、qtwebengine。QtPdf 属于 qtwebengine。遵循归档内 README、configure/CMake 和 pyside-setup 的 build_scripts；需要 Visual Studio C++、CMake、Ninja，构建 QtPdf 时按 qtwebengine 的 QtPdf 构建目标与先决条件。上游发布构建未在本机从原生源码完整重建；便携版采用对应官方 Windows wheels。未修改 Qt 原生代码。
- 其余 LGPL/GPL/MPL 组件的匹配源码同在 source-materials。其他 Python 依赖按锁文件安装官方包；版权与原生第三方声明保留于 LICENSES。
- 运行时包含两个同版本 OpenCV wheel 的共享路径；实际文件与 opencv-python 5.0.0.93 匹配。Tencent 命名空间的共享文件与 tmt 3.1.129 匹配。精确记录见 LICENSES/build-provenance.json，实际文件副本在 source-materials/overrides，重建后按该目录覆盖相同相对路径。

本版采用动态 Qt DLL。接收者可依各组件许可证修改、替换和重新构建；应用不进行第三方 DLL 签名锁定。许可证允许的反向工程与重新链接权不受额外限制。编译所得二进制不保证逐字节可复现。
