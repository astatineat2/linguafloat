# LinguaFloat 使用指南

适用于 Windows 11 x64。首次使用可先完成“安装与启动”和“配置翻译服务”，再按场景选择翻译方式。

## 安装与启动

已使用 CC Switch 或 OpenCode 的用户，可进入“配置设置 → 数据管理”，选择 SQL 文件批量导入其中全部类别（不再提供本机配置直接读取）。导入后点击“返回全部配置”查看供应商卡片，缺失项在结果详情中补全。支持范围及重复配置处理见 [配置交换指南](CC-Switch导入.md)。导入不自动启用或调用翻译接口。

v0.17.0 build1 当前为候选版，安装验收尚未完成，Release 仅准备草稿；公开稳定版仍为 v0.11.1。下面的首次配置及新界面说明适用于 v0.17.0；稳定版按其随包指南操作。

1. 公开稳定版从[最新稳定版](https://github.com/astatineat2/linguafloat-releases/releases/latest)下载。候选版正式提供下载后，可选完整 `LinguaFloat-v0.17.0-windows-x64-portable-build1.zip` 或 `LinguaFloat-v0.17.0-windows-x64-setup-build1.exe`；普通使用无需源码包。
2. 完整解压到当前用户有写入权限的目录，例如 `D:\Apps\LinguaFloat`，运行 `LinguaFloat.exe`。无需安装 Python。
3. 保留 `_internal`、`document-runtime`、`LinguaFloatUpdater.exe` 等依赖和资源，不要只复制 EXE，也不要混用不同版本的文件。

主窗口默认显示，页面为“功能设置 / 配置设置 / 文件翻译”。关闭主窗口会收进系统托盘；单击或双击托盘图标可重新打开，托盘菜单的“退出”才会结束程序。

v0.17.0 build1 完整 ZIP 约 501.4 MiB，安装包约 371.2 MiB，完整运行文件共 1325016159 字节（约 1.23 GiB）。安装包压缩较小不代表安装后更小。安装临时空间峰值未实测，需另外预留解压和备份空间；首次 PDF 处理的资源下载另计。

便携版完整解压后运行 `LinguaFloat.exe`。安装版设计流程为欢迎、安装位置、快捷方式、安装进度、完成；可手动输入安装目录、选择桌面快捷方式并在完成后启动。目录新建与命名、完整安装及卸载仍待验收，不将设计行为视为实测结论。已有配置、历史及密钥继续使用原存储，安装和卸载脚本不主动清除用户数据；仍建议升级前备份。

程序当前没有 Windows Authenticode 签名。请从正式发布页下载，使用同版 SHA256SUMS.txt 核对文件，不要关闭安全软件。

## 配置翻译服务

首次启动显示单页“配置翻译服务”：选择 OpenCode Go、Now Coding 或自定义服务，填写接口地址、API Key 和模型，点击“完成并保存”后启用。密钥继续由系统凭据管理器保存；保存不会自动测试或翻译。

“获取模型”只在主动点击时请求供应商，可能需要先填 API Key；失败时可手动输入模型。选择“跳过，稍后配置”直接进入主界面，不创建空白供应商。保存或跳过后不会再自动弹出，后续仍从“配置设置 → 添加供应商”配置。

1. 打开“配置设置”，选择“新增配置”，填写供应商名称、Base URL、API Key 和模型。
2. 按供应商文档选择 Responses、Chat Completions、Anthropic Messages 或 Gemini generateContent。模型可手动填写；“获取模型”失败不影响手动配置，获取列表成功也不等于能翻译。
3. 点击“测试连接”，核对结果，再点击“保存配置”。连接测试使用当前表单，包括尚未保存的内容。
4. 点击“使用此配置”，或在“功能设置”的“当前配置”中选择它。保存与启用是两个操作；功能设置页显示的配置和模型才是日常翻译所用。

“测试连接”和“一键测试”会主动发送真实短文本请求，可能产生 API 费用；首次启动、打开指南及检查更新不会调用翻译 API。正式翻译会将文字发送给所选供应商，账户权限、额度及费用以供应商为准。

配置支持搜索、收藏和复制。页面切换保留当前草稿，切换编辑项目或退出时会提示未保存的修改。文件翻译自动跟随当前启用配置和模型；启动后的任务使用当时的配置快照，之后切换只影响新任务。

### 接口与高级参数

Base URL 按供应商文档填写，地址建议需要主动点击才应用；自定义路径不会被强制补成 `/v1`，末尾接口路径及重复 `/v1` 会规范化。远程服务使用 HTTPS，本机地址才允许 HTTP。

不同协议不代表所有模型都兼容；不要仅凭模型名称切换接口。OpenAI 模式的“检测接口”经确认会测试 Responses 与 Chat，原生模式仅测试当前协议，再由你决定是否应用结果，不会自动更换供应商。

超时、重试和文档并发按供应商配置。文件翻译的请求超时范围为 30–600 秒；普通区域、输入与功能自检为避免重复费用，不自动重试。高级设置的输出 Token 上限为 0 时使用接口默认行为；Anthropic 必须指定 max_tokens，使用 4096，其余接口不发送长度参数；Chat 参数名、指令角色、推理强度及供应商思考开关，仅在对方明确要求时调整。

API Key 按供应商保存到 Windows 凭据管理器，默认掩码显示，可用眼睛图标查看；不写入普通 config.json。也可指定密钥环境变量，有值时优先使用。直接填写新密钥并保存会清空该配置的环境变量名，确保新密钥生效；不修改系统环境变量。

### Codex 配置导入与导出

导入导出统一在“配置设置 → 数据管理”中操作，编辑窗口不再提供旧的 Codex TOML 交换入口。SQL 默认不含密钥，主动勾选才写入明文密钥；导入 CC Switch 时属于整库恢复，请先备份。Codex 登录凭据不等于 API Key。

## 选中文字翻译

1. 在目标软件中选中文字，按 `Ctrl+Alt+T`；或在选区右键后点击附近的“翻译”按钮。
2. 在悬浮窗查看结果。默认中文译为英文，其他主要语言译为简体中文。

触发方式可选择快捷键、右键或同时启用。右键本身不发送请求，也不改写目标软件的原生菜单。快捷键会优先读取系统选区，必要时等待复制结果；右键入口不会自动模拟复制。

部分游戏、图片、自绘控件或受保护页面无法直接取词；可先手动复制，再点“翻译剪贴板文字”，或使用区域 OCR。取词兼容性需按实际软件验证，不保证所有程序可用。取词诊断只记录步骤和格式，不记录正文或密钥。

## 输入翻译：把想说的话译成外语

1. 在“功能设置”选择输入翻译的目标语言，例如英语。
2. 在目标软件的输入框中输入中文，按 `Ctrl+Alt+Y`；可选中一段，或读取可访问的当前编辑框。
3. 成功后，译文显示在悬浮窗并自动复制。回到聊天窗口，自行按 `Ctrl+V` 粘贴和发送。

程序不会自动替换或发送消息。无法读取的输入框可先选中文字再试，或手动复制后翻译剪贴板。输入快捷键可修改，不能与选中翻译相同。切换悬浮窗目标语言会重新翻译当前文字，可能产生新的请求。

## 屏幕区域翻译与游戏模式

1. 点击“选择区域”，拖出包含对话或字幕的矩形；Esc 或右键取消。
2. OCR 在本地识别，稳定文字再交给所选供应商翻译。默认每秒检查画面，请求最短间隔 3 秒，可在功能设置调整；不是逐帧即时字幕。
3. 绿色区域框的四边和四角可缩放，顶部中央短柄可平移；译文窗也可拖动、调整大小，内容自动换行。
4. 主窗口与区域译文窗均可暂停、继续或停止。暂停后不继续截图、OCR 或提交新请求；此前请求返回只允许缓存，不更新旧译文或错误。暂停时移动绿框不会自动恢复识别。

每次框选一个显示器内的区域，不自动跟随游戏窗口移动；跨屏、改变分辨率或缩放后请重新框选。静止画面和匹配译文可复用缓存，避免反复提交同一内容。

游戏模式可以“关闭 / 始终开启 / 自动”。“自动”需通过“添加游戏”选择实际运行的游戏 EXE；启动器不一定是游戏本体。游戏模式仅保留区域翻译，暂停普通取词和输入快捷键；想把中文转英文时，需切回普通模式再使用输入翻译。

开启游戏模式不会自动截图，需要先选择区域。窗口化或无边框通常更适合截图与浮窗；独占全屏、受保护画面和部分反作弊环境可能无法使用。程序不注入游戏进程，不保证所有游戏兼容。

## 文件翻译与阅读文献

1. 打开“文件翻译”，添加 PDF、DOCX、PPTX 或支持的扫描图片，选择原文/译文语言与保存目录。
2. PDF 默认“保留版式”；也可选“阅读版 / 本地 OCR”。输出可选纯译文、双语或两者；PDF 双语支持左右并排或原译交替，Word/PPT 的排列方式按各格式现有实现处理。
3. 不确定效果时先试译，输出文件名前有“试译版”；确认后再处理完整文件。试译和正式翻译都可能消耗 API 用量。
4. 查看各文件进度与错误详情；完成项目移到历史记录，历史可查看实际耗时和供应商返回的输入/输出 Token，用量未返回时显示未知。

输出目录、语言、译文排版、图表开关、输出种类与双语排列会恢复上次选择；页码、试译、暂停和“仅重新排版”等临时任务选项不会沿用到新任务。

“翻译图表内容（表格＋图内文字）”适用于 PDF/图片的保留版式处理，默认关闭；用于图表内自然语言，不改写数值、单位或公式。表格译文按整表统一字号，先换行再缩字号，保留 6pt 下限及原有小字保护。复杂纹理、合并表格、多子图或无法安全定位的内容可能保留原文并给出具体诊断，需要检查输出。

参考文献默认保留原文和原有版式，不再需要勾选；识别到后续附录或补充材料后继续翻译。可用于试译和指定页码。无法安全分离的局部范围保留原文并标记；未确认参考文献范围时会给出说明，不代表所有边界均已识别。

“仅重新排版”复用匹配的已保存译文，不发送翻译 API 请求；缺少缓存时停止并说明缺失范围。它不能修复译文本身错误，调整翻译配置后也不能保证复用不兼容缓存。

### 列表、暂停与缓存

待翻译与历史列表都可拖动表头分隔线调整列宽，双击适配内容；总宽度超出时横向滚动，宽度分别保存。“恢复列宽”仅重置当前列表。长文件名和状态悬停可查看完整内容；待翻译状态悬停可看 Token，用量未知不会冒充零。

“移除所选”只移除界面条目，不删除源文件、输出或缓存；正在处理的项目应先取消。暂停不撤回已发送请求，返回内容可进入缓存；取消后可重新开始并复用匹配缓存。仅在输出保存并校验成功后报告完成；有保留区域时查看详情，不把“部分完成”当作全部成功。

### 第一次处理 PDF

完整包包含屏幕 OCR 资源。PDF 引擎可能下载缺失的布局模型、字体，实际下载量取决于缺失项；本机缓存总体积不是每位用户的必需下载量。

这些资源下载不消耗翻译 Token；正式翻译会发送文字给配置的供应商并可能计费。资源下载失败时检查网络和实际诊断，不要把资源等待等同于模型响应慢。

## 设置与数据位置

| 内容 | 位置 |
| --- | --- |
| 设置 | `%APPDATA%\LinguaFloat\config.json` |
| 文件任务、译文缓存和历史 | `%APPDATA%\LinguaFloat\documents` |
| PDF 模型和字体 | `%USERPROFILE%\.cache\babeldoc` |
| 软件更新下载和恢复记录 | `%LOCALAPPDATA%\LinguaFloat\updates` |
| 翻译结果 | 自己选择的输出目录 |

日常文字翻译使用内存缓存，重启后不保证保留；文件译文缓存持久保存，两者不要混为一谈。API Key 使用 Windows 凭据管理器或环境变量，不随便携包迁移；换电脑通常需重新填写。

## 更新与恢复

“帮助与更新”可随时从主窗口或托盘打开，也可重新查看首次指南。默认每天首次启动检查公开稳定版，可关闭自动检查；检查访问 GitHub，不上传论文、配置或密钥。检查失败不代表已经最新。

发现新版后可下载，支持暂停和续传；元数据签名、包大小、SHA-256、版本及结构通过校验后才安装。安装助手等待任务安全结束：暂停任务需继续或自行取消，持续区域翻译需先停止，不要强行结束后台来更新。

新版暂存和完整旧版备份需要磁盘空间；程序目录旁的 `LinguaFloat-backups` 保留旧版。启动失败时尝试回退，并保留更新事务记录。配置、缓存、历史与输出不会因更新主动删除，数据库迁移前备份；回退读取数据仍受格式兼容性限制。

若提示需要恢复，可按诊断使用该次下载目录的 `LinguaFloatUpdater.exe --job 完整目录 --recover`；不要混用不同版本依赖或先删除备份。无法写入安装目录时，先处理目录权限或使用完整包在可写目录部署。

## 常见问题

- **快捷键无效：** 检查是否被其他软件占用，在功能设置修改或重试监听。
- **400：** 核对接口、地址、模型和参数；缺少会话标识还需核对服务的正式用途，不能仅改模型或超时。
- **401/403：** 检查密钥、模型权限、工作区及服务使用范围。能列模型不等于有调用权限。
- **402：** 核对供应商给出的计费原因、对应账户余额和预算；若写明上游资金不足，不要直接认定必须给个人账户充值。
- **429：** 限流或供应商额度限制，按提示等待，避免反复启动任务。
- **超时或无法连接：** 检查网络、代理及服务状态，区分本地资源等待、API 等待与排版。
- **保存失败：** 检查输出目录权限、剩余磁盘空间和具体页码/区域原因。
- **更新或 PDF 资源下载失败：** GitHub API 可达不代表附件域名可达，可使用自己的代理；软件不会替你修改全局网络设置。

复杂文档的漏译、重叠、公式和上下标需要人工检查；任何模式都不承诺所有论文无损。软件适用源码、第三方声明、匹配对应源码与完整更新日志可从[公开下载仓库](https://github.com/astatineat2/linguafloat-releases)获取。构建者另见[对应源码与构建说明](https://github.com/astatineat2/linguafloat-releases/blob/main/开发与构建.md)。

## 区域翻译与快捷键

点击快捷键框后按键录入，Esc 取消，再点对应保存按钮。区域框内部按住左键直接移动，四边和四角缩放；内部不会穿透操作下面的软件，停止区域翻译后恢复桌面操作。选区显示实时桌面，不使用冻结截图或暗色遮罩。暂停或停止 2 分钟后释放 OCR 模型，下一次可能需要重新加载。稳定约 1 秒后首次识别，译文逐段显示。计时图标中可调整识别及翻译最短间隔。分段请求有最多两段并发与冷却限制，可能增加提示词用量。
