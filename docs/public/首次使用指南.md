# LinguaFloat 首次使用指南

支持 Windows 11 x64。请从 <https://github.com/astatineat2/linguafloat-releases/releases> 下载完整便携 ZIP。

## 安装与启动

1. 下载 `LinguaFloat-v版本号-win-x64.zip`，不要误下载源码包。
2. 完整解压到当前用户可以写入的目录，例如 `D:\Apps\LinguaFloat`。
3. 启动 `LinguaFloat.exe`。无需安装 Python；不要只复制一个 EXE。
4. 保留 `_internal`、`document-runtime`、`LinguaFloatUpdater.exe` 等依赖和资源。

主窗口默认显示。关闭窗口通常会收进托盘；双击托盘图标可再次打开，托盘菜单可真正退出。
当前程序没有 Windows Authenticode 签名；请使用正式下载地址并核对 SHA-256。不要关闭安全软件。

## 配置翻译服务

进入“配置设置”，填写供应商、接口地址、API Key 和模型。按供应商文档选择 Responses API 或 Chat Completions，保存后在“功能设置”启用配置。

“测试连接”会主动发送一次真实短文本请求，可能产生 API 费用。软件启动、打开指南和检查更新不会发起翻译 API 请求。
文件翻译跟随当前启用的供应商与模型；切换配置只影响以后启动的任务。

## 翻译方式

- 选中翻译：选择文字后按 `Ctrl+Alt+T`，或使用右键翻译入口。
- 输入翻译：默认 `Ctrl+Alt+Y`，支持修改快捷键。
- 区域翻译：框选屏幕区域，本地 OCR 后翻译；可以暂停、继续、拖动及缩放。游戏模式仅保留区域翻译。
- 文件翻译：添加 PDF、DOCX 或 PPTX，选择保存目录及输出方式，再开始。试译结果名称带“试译版”。

PDF 默认保留版式，上次选择会保存。“参考文献及后续内容不翻译”开启后，可靠识别到的参考文献章节及文件后续内容保留原文。

## 第一次处理 PDF

完整包已经包含屏幕 OCR 资源。PDF 引擎还可能联网下载缺失的布局模型、字体等文件，实际下载量取决于缺失项；本机已有缓存大小不能当作所有用户的必需下载量。

这些本地资源下载不属于翻译 API 请求，也不消耗翻译 Token。正式翻译会将识别出的文字发送给你选择的供应商，可能计费。首次启动不会自动上传或翻译论文。
资源下载失败时，请检查网络、系统代理和完整包资源。不要把资源下载慢误认为模型翻译慢。

## 设置和数据位置

| 内容 | 位置 |
| --- | --- |
| 设置 | `%APPDATA%\LinguaFloat\config.json` |
| 任务、译文缓存和历史 | `%APPDATA%\LinguaFloat\documents` |
| PDF 模型和字体 | `%USERPROFILE%\.cache\babeldoc` |
| 软件更新下载和恢复记录 | `%LOCALAPPDATA%\LinguaFloat\updates` |
| 翻译结果 | 自己选择的输出目录 |

API Key 使用 Windows 凭据管理器或指定的环境变量，不随便携包分发。移动软件目录不会迁移凭据；换电脑通常需要重新填写 Key。

## 更新与恢复

打开“帮助与更新”。默认每天首次启动检查公开稳定版，可关闭自动检查。检查只访问 GitHub 发布信息，不上传文档、配置或密钥。

发现新版后可下载，支持中断后续传。下载和安装前验证签名、大小、SHA-256、版本及包结构；校验失败不会覆盖旧版。
选择“安装并重启”后，助手等待当前任务安全结束。暂停任务需要先继续或自行取消，持续区域翻译需要先结束。
不要强行结束主程序或后台来提早更新。安装盘需同时容纳新版暂存和保留的旧版。

更新助手位于程序目录之外，备份保存在程序目录旁的 `LinguaFloat-backups`。失败时尝试回退，更新下载目录保留事务记录。
若提示需要恢复，可运行该次下载目录中的 `LinguaFloatUpdater.exe --job 完整目录 --recover`；不要删除备份或手工混用不同版本依赖。
配置、缓存、历史和翻译结果不会因更新而主动删除。数据库迁移前备份；只有兼容数据才可由旧版读取。

## 常见问题

- 快捷键无效：检查其他软件是否占用，在功能设置中查看监听错误并重试。
- 401/403：检查密钥、账户和模型权限。
- 400：核对接口模式、地址及供应商支持的参数。
- 429：供应商限流，等待后再试；不要反复启动任务。
- 保存失败：选择有写入权限的输出目录，检查磁盘空间。
- 无法检查更新：可能是网络、代理、GitHub 限流或尚未发布正式版本；这不代表已经是最新版。
- PDF 或 OCR 资源缺失：使用完整包，检查资源下载网络和诊断原因。

帮助可以随时从主窗口或托盘菜单重新打开。
