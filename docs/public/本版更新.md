# LinguaFloat v0.17.0（候选版，Release 草稿）

分发构建为 build1。安装验证仍暂停，本轮只准备草稿，公开稳定版仍为 v0.11.1，不切换自动更新通道。下列安装改动描述代码实现，不能视为完整安装验收通过。下载大小、验证范围及限制见[发布说明](发布说明-v0.17.0.md)。

- 安装目录可浏览并新建命名文件夹；移除重复汇总页及完成页冗余文字和紫色竖线。
- 首次进入单页配置翻译服务，包含预设、自定义、模型获取、默认快捷键；可以跳过稍后配置。
- 保存采用现有安全凭据存储，不自动发起模型列表或翻译请求；已有配置与历史保留。
- 无新增依赖或翻译算法变化；首次文档引擎资源缺失时仍可能需要下载。

## 延续 v0.16.3 修复

- 修复静态区域长译文持续卡顿的排版循环。
- 改善变量修饰线、旋转图文字坐标与正文术语关联；不新增模型调用。
- Now Coding 添加移除本地来源，快捷键统一由底部“保存功能设置”保存。

本版简化供应商添加、快捷键设置和文件工作区，列宽可随窗口自适应，任务详情位于列表下方。文件翻译默认保护参考文献，后续附录继续翻译；对无法可靠分离的局部范围保留原文并明确说明。保留现有用户数据与任务控制，不增加依赖或自动付费请求。

## 延续的界面与局部保留机制

本版按 Privacyboard 指南统一浅灰紫工作台、页面、菜单、卡片和中文弹窗，正文采用 14 逻辑像素。文件页顶部添加文件、底部固定翻译与结果操作；紧凑设置区、真实任务状态、细进度条和详情分别呈现。窗口较窄时导航收窄、操作换行；配置页仍为“全部配置”，数据管理和添加供应商保持相邻。

翻译、API 适配、缓存、历史与用户配置保持原有逻辑；未新增依赖或自动付费请求。下列 v0.15.7 局部失败保留机制继续保留。

- 个别区域识别、翻译、公式校验或排版失败时保留原文，其他内容继续输出；PDF 中用红框及“未翻译”标记，Word 使用红色段落框，PPT 使用红色波浪下划线。
- 任务显示“已完成，X 处未翻译”，输出目录附位置和原因说明及脱敏日志；未知漏识别位置不能保证全部发现。阅读版无法定位到小区域时保留整页。
- 失败内容不作为合格译文或完整快照缓存。仅重新排版缺少缓存的局部保持原文，不自动补译；暂停取消继续生效，鉴权、额度及输出损坏等全局错误仍停止。
- 本轮使用本地模拟接口验证，没有真实 API 调用；没有新增依赖或更换引擎。

## 保留的 v0.15.6 修复

- 公式旁文字补译遇到空译文、夹带公式等问题时，在现有重试额度内只修复不合格片段。保留其他合格片段、原公式及缓存，不自动重译整篇论文。
- 修复与网络重试共用同一额度；局部额度用尽后保留原文并报告具体原因。主动翻译中的补译可能增加请求与费用，“仅重新排版”仍不发请求。
- 保留暂停、取消、有限并发及任务配置隔离。成功修复写回对应缓存，不新增依赖或更换引擎。
- 完整流程使用实际 PDF、既有缓存及模拟响应验证；本轮没有真实 API 调用，不代表真实翻译质量已经验证。

## 保留的 v0.15.5 修复

- 延续部分无标题、上标编号参考文献的识别。通过连续条目、文献特征及本地版面核对后保留原文；本版已将保护范围改为仅参考文献，后续可识别的附录继续翻译。
- 本版不再因缺少参考文献边界直接终止全文。能定位但无法安全分离的范围保留原文并说明；完全未可靠识别时明确警告，不宣称已保护全部参考文献。
- 使用实际 PDF 与模拟 API 验证，未调用真实翻译服务；不会覆盖用户配置、缓存和历史。

## 保留的 v0.15.4 改进

- 文件翻译在已有请求中加入有限原文上下文和相关缩写定义候选，帮助模型理解科研段落；不会发送整篇论文作为每段的上下文。
- 修复扫描页隐藏 OCR 字号影响译文字体的问题，改善行末连字符与分离文本区域处理。
- 修复部分公式底字与上标被拆开排版的问题，继续保留原始公式字形。
- Office 多格式段落加强正文、格式标签及小数／百分比校验，拒绝可检测的不完整输出。
- 没有新增设置页、依赖或额外模型请求。额外上下文会增加输入用量，实际费用依供应商计价。
- 旧缓存、历史和配置保留；新策略不会复用旧译后快照，选择“仅重新排版”且缺少匹配缓存时会停止，不自动调用 API。
- 保留公式、参考文献、递归修复、暂停取消与 Go 适配。工程改进已验证，实际翻译质量提升仍待验证；本轮无真实 API 调用。
- GUI 与完整文档运行时统一升级。本轮同步当前源码并准备草稿，不正式发布远程更新。
