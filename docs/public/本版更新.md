# LinguaFloat v0.11.1

- 修复 GitHub 未登录 API 限流时无法检查更新：改读公开稳定版的签名更新附件，保留完整验证。
- 新增“帮助与更新”以及可重新打开的首次使用指南。
- 新增公开稳定版检查、每日检查开关、签名更新说明、完整包校验、下载进度和中断续传。
- 新增独立更新助手：等待任务安全结束，备份完整旧版与迁移前数据，替换程序，检查新版启动，失败回退。
- 发布文档采用公开白名单，新增依赖许可清单和本地发布资料生成工具。
- 保留翻译、OCR、游戏模式、配置、缓存、历史及固定本地启动目录。

更新功能需要发布仓库存在正式签名附件。v0.10.0 及更早版本需手动下载含更新器的完整包。
当前没有 Windows Authenticode 签名。完整包附第三方声明，发行附件另含匹配对应源码。已在本机隔离配置、无 Python PATH 下验证启动；尚未在全新 Windows 虚拟机验证。
