# LinguaFloat v0.23.2

公式旁文字的补译如果重复出现数值错误，改为只发出错片段，锁定原始数字并在译后原样回填，再检查数字、单位和公式。对未指明参数的通用 HTTP 400，已有成功响应的任务在重试额度内最多补发该请求一次。现有 PDF 不会被改写。

## 此前的 v0.23.1

参考文献根据作者、刊名、年份、卷页、文章号、DOI 等证据组合识别。编号、缩进和分栏用于定位，不单独决定是否保留原文。修复了部分编号正文被误归入参考文献、因此整段留在译文侧的问题，也改善了无编号和跨行条目的保护。

改善图引用、上标引文及小数附近的正文处理。已生成的 PDF 不会被覆盖；重新生成时才应用这些修复。公开提供 Windows x64 Setup；已安装的 Setup 版可在「帮助与更新」检查更新。

## 此前的 v0.23.0

新增「译后校对」。英译简中正文双语 PDF 保存后自动离线查找整段原文残留，提示疑似缺段和未检查页。点击问题可打开成品对应页。可选 AI 校对默认关闭，只提交必要片段、不自动覆盖译文。

「译文导出」可直接选本地 PDF，也可选历史结果。没有编辑底稿时，Word 和 Markdown 从 PDF 恢复可编辑文字。含图片资源的 Markdown 以 ZIP 交付。转换不会调用翻译接口；扫描、复杂公式和表格需对照原 PDF。

本地版面检查与 AI 语义校对分别显示。参考文献不翻译，但仍会检查文字覆盖及可比对的链接；修复了右栏先于左栏参考文献标题起排时漏识别的问题。

历史结果列表显示版本、时间和可导出格式。若因目录迁移找不到结果，新版会先在已知输出目录核对，也可手动选择原任务的结果文件。无法核实归属的文件不会被自动关联。

已有译文不会被重写。新版本以 Windows x64 Setup 分发，不通过旧便携版的更新助手迁移。

## 此前的 v0.20.1 · Windows 安装候选版

安装包名为 `LinguaFloat-v0.20.1-windows-x64-Setup.exe`。本次改进作者年份格式参考文献的保护，并在能确认位置时恢复邮箱及网页链接。部分表格仍可能漏译，参考文献起始页混有正文时仍需核对。安装版从开始菜单启动，支持通过“帮助与更新”校验后续 Setup。本版不处理旧便携版迁移。

## 此前的 v0.19.11 · 便携版原地更新

修复普通账户不能在系统盘根目录新建锁文件的问题；回退时立即释放历史库的备份连接，避免恢复时遇到 Windows 文件占用。

更新目标取自当前运行的主程序，支持盘符下一级的独立文件夹，不替换盘符或混有其他顶层文件的目录。v0.11.0 / v0.11.1 用户：若曾遇到“程序安装目录无效”，请只打开要更新的那份旧版，运行本发布页的 `LinguaFloat-Repair-v011.exe`，确认显示的路径，再到旧版「帮助与更新」检查、下载、安装并重启。不需要移动程序或重新配置。工具只接受两款公开旧版及其已知助手，核对发布者签名后才更换助手；整个升级包仍须通过原发布公钥校验。
