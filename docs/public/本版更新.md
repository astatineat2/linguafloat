# LinguaFloat v0.19.3

- 修复可靠原生表头的碎片化定位：中文与科学标识组成完整单元格内容，紧凑换行，按实际字形整体居中。
- 科学标识保留原始矢量字形、字号、斜体和上下标，继续执行安全擦除与墨迹碰撞检查。片段缺失或空间不足时保留原文，不移动数据或表格边界。
- 复用已有译文离线重排，正文、数据区和图片布局不变。扫描或结构不明确的表头不强制重组。

## v0.19.2 本地修复

- 新建 PDF 保留版式正文任务默认翻译独立表格。三线表可依据真实表头边界和原生文字行列处理，翻译表头、说明和化合物常用名称；保留数据、单位、公式、表线与背景。无法安全放入的内容仍保留并记录。
- 底部按钮改为“图片翻译”，只负责正文完成后的图内文字补译，不再要求手动开启独立表格；原确认、取消、自定义历史任务、材料检查和编号另存流程保留。
- 新旧表格策略缓存隔离；旧任务未译表格不静默改成已完成，图片内嵌小表仍按整图保护。
- 删除帮助窗口初始说明行，保留动态更新状态、下载和关闭逻辑。

## v0.19.1 本地修复

## v0.18.1 本地修复

- 修复中文语序调整引发的样式误拒绝、等价字体状态导致的碎片化、学名空格丢失，以及引用上标脱离所属正文。保留原生数学字形和粗斜体。
- 新任务默认宋体＋Times New Roman，中文可选微软雅黑；旧用户需明确确认，保留原字号层级及粗斜体。本机字体缺失明确提示，不随包分发系统字体；宋体粗斜体采用有记录的受控合成。
- 正文先完成，任务详情独立“翻译图表”，图内文字/独立表格分选；沿用原页码、正文和合格缓存，编号另存，不覆盖旧结果。校验父任务、配置、原文件、正文及页映射，旧任务缺补译材料时明确提示，不自动重翻。
- 修复装饰标题、括号编号参考文献、作者条目结构与姓名保护；参考文献原文恢复，后续附录仍译。统一字体并记录局部字号调整，换字体可复用本版兼容译文快照。
- 文档术语候选保留来源及歧义；图文使用相关正文/图注有限上下文，避免将首次结果强定为词库。按真实单元格和独立安全组回填，保留科学数值及原字形。
- 增加有原生分组证据的导航中文回填，正文流程也执行前置信息修复；修复关键词拆分及参考文献裁剪穿过页码字形的问题。
- 改善图表中独立标签、旋转文字和表格文字的安全排版。密集科学图约 4pt 小字仍可能保留原文；不会为提高成功数覆盖数据、图线或缩成不可读文字。
- 使用同一问题 PDF 验证了真实正文和第 6 页表格，缓存重排不新增请求；其余图表主要为模拟及结构验证，全文语义、部分内部链接与文本搜索仍需核对。
- GUI与文档运行时共同更新；不制作安装包、不改远程自动更新通道。本轮真实验证仅发送已获授权的文本和有限上下文，不提供论文上传服务。


本版累计包含上述本地修复，提供完整便携包、匹配的对应源码及校验文件；不制作安装包，安装验收仍暂停。本次供手动下载，原签名更新通道保持不变。复杂图文和译文语义仍需核对，不承诺所有文档无损还原。详情见[本版发布说明](发布说明-v0.19.3.md)。
